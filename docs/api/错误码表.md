# Signal 错误码表（中文）

统一格式：`module.reason_code`。HTTP 响应体见 `server-core` 的 `ErrorBody`（含 `code`、`message`、可选 `trace_id`）。

前端、审计、`safe_context`、健康快照应使用同一错误码，不写原始凭据或堆栈。

## 核心（BACKEND / AGENTS 必列）

| 错误码 | 含义 | 典型 HTTP |
| --- | --- | --- |
| `collector.qr_expired` | 二维码已过期 | 400/410 |
| `collector.needs_relogin` | 采集登录需重新扫码 | 409 / health |
| `connector.unsupported` | 连接器未注册或未验收 | 400 |
| `source.initial_validation_failed` | 首次验证失败（不足成功篇） | 400 |
| `egress.network_unreachable` | 出口网络不可达 | 502 / health |
| `crawler.blocked_by_protection` | 平台防护/验证码/登录墙 | needs_action |
| `image.filtered` | 图片被过滤（装饰/过小等） | 业务决策 |
| `ocr.failed` | OCR 失败 | job 失败 |
| `health.snapshot_unavailable` | 无可用健康快照 | 404 |
| `token.scope_denied` | API Token 缺少 scope | 403 |

## 采集登录 / 出口

| 错误码 | 含义 |
| --- | --- |
| `collector.qr_not_found` | 二维码会话不存在 |
| `collector.qr_failed` | 扫码失败/拒绝 |
| `collector.advance_not_allowed` | 非 fake 连接器禁止推进二维码 |
| `collector.invalid_advance_status` | advance body 状态非法（仅 scanned\|confirmed） |
| `collector.not_found` | 采集账号不存在 |
| `collector.invalid_transition` | 非法状态迁移 |
| `collector.probe_failed` | 探测失败 |
| `egress.not_found` / `egress.inactive` | 出口不存在或停用 |
| `egress.purpose_mismatch` | 用途与出口种类不匹配 |
| `egress.provider_required` / `egress.provider_failed` | 供应商问题 |
| `egress.degraded` | 出口降级（health） |

| `source.invalid_url` / `source.invalid_id_type` | 输入无效 |
